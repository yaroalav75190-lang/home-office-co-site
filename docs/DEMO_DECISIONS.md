## Языки (05.11)
- Три версии: русская (основная, без префикса в адресе), английская `/en` и испанская `/es`. Переключатель RU · EN · ES в шапке и меню ведёт на ту же страницу на другом языке. В разметке hreflang ru/en/es, x-default ведёт на русскую версию; индексируемые страницы всех трёх языков в sitemap (15 адресов).
- Тексты переведены целиком, факты те же. Бюджеты квиза в долларах. Блок «Оплата из России» в переводах называется «Оплата из-за рубежа» (Payment from abroad, Pago desde el extranjero), смысл тот же.
- Заявки с английской и испанской версий приходят брокеру на русском, со строкой «Язык сайта: English» или «Язык сайта: Español».
- Подтвердить: кто отвечает на заявки на английском и испанском, есть ли испаноговорящий брокер. Если нет, до запуска либо найти, либо убрать испанскую версию из переключателя.
- Открыто: факт о прямых рейсах из Москвы в разделе «Что нужно знать о Пхукете» остался и в переводах; для иностранной аудитории его можно заменить нейтральным («прямые рейсы из Европы, Азии и Ближнего Востока»). Страница 404 для `/en` и `/es` пока общая русская. Переводы сделаны для промо; перед запуском — вычитка носителем языка.

## Показ на Vercel (07.11)
- Ссылка для клиента: https://home-office-co.vercel.app — проект `home-office-co` в аккаунте Vercel клиента (Root Directory `site`, Node 24). Защита Vercel Authentication для проекта выключена: иначе вместо сайта открывался бы вход в Vercel.
- Проект не связан с GitHub (у аккаунта Vercel нет подключения к GitHub), поэтому слияние в `main` сайт не обновляет. Новая версия выкладывается из корня репозитория командой `vercel deploy --prod` с `VERCEL_ORG_ID` и `VERCEL_PROJECT_ID` этого проекта; что загружать, задаёт `.vercelignore` (только `site/`, без `node_modules`, сборок и `photos-src`). Чтобы обновлялось само, подключить GitHub в настройках аккаунта Vercel (Login Connections) и связать проект с репозиторием.
- Переменные окружения проекта на Vercel: `LEAD_DEMO_NO_DELIVERY=1` (формы показывают «спасибо», заявка пишется только в журнал Vercel и брокеру не приходит) и `SITE_NOINDEX=1` (вся версия закрыта от поисковиков: заголовок `X-Robots-Tag`, `noindex` на страницах, robots.txt запрещает всё).
- Адрес для canonical, hreflang, sitemap и картинок превью в мессенджерах берётся из адреса проекта на Vercel (`<проект>.vercel.app`), пока не задан `NEXT_PUBLIC_SITE_URL`.
- На запуске: подключить amoCRM и Telegram, убрать обе переменные, добавить домен.

## SEO перед запуском (технические флаги)
- Банг Тао: `ready: true` в `districts.ts` после проверки брокером — страница уйдёт в индекс и sitemap.
- `/privacy` и `/consent`: снять noindex и включить `LEGAL_INDEXABLE` в `sitemap.ts` после проверки юристом.
- Домен: `homeofficeco.com` — запасной адрес в `SITE_ORIGIN` (`site-url.ts`), из него же `metadataBase`, robots.txt и sitemap. На Vercel адрес берётся из домена проекта; другой домен — задать `NEXT_PUBLIC_SITE_URL` или поменять запасной.
- HSTS включён в заголовках; на боевом домене проверить, что HTTPS работает на всех поддоменах.
- Отдельными задачами: CSP с nonce (Метрика), статическая `/podbor` (сейчас динамическая из-за параметров квиза), карточки OG 1200×630, PNG-логотип.
