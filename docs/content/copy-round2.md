# Тексты, раунд 2: правки по QA раунда 1 (пункты 2–5)

Версия 1.0, 2 ноября 2026. Автор: ru-copywriter. В скобках знаки с пробелами.

Правило заглушек (QA §2). Видимая заглушка остаётся только для данных клиента, которые нельзя знать: телефон, почта, юрлицо, часы, имена и фото команды, отзывы, год открытия, названия проектов. Форма тихая: `[заглушка: …]` из одного-двух слов. Её рендерит `Stub` (Small, ink-muted), в крупном кегле её нет. Внутренние пометки для команды («утвердить», «сверяет юрист», «в плане») на сайт не выводим, они живут в этом файле и в списке для клиента.

## 3. «Форматы, с которыми работаем»

Экспорт: `formats` и `formatsHeading` в `site/src/components/sections/phuket/content.ts`. Рендер: `site/src/components/sections/phuket/formats.tsx` на `/thailand/phuket` и на странице Банг Тао.

Почему такие фото. Формат на снимке показывает только `villa`, поэтому подпись «Пример формата» стоит только у виллы. Квартир и таунхаусов в `photos.ts` нет. Для них взяты места, где такой формат встречается, и подпись называет место, а не формат. Банг Тао дал самую большую долю новых кондоминиумов острова (Knight Frank 2022–2025). Раваи и Най Харн связаны с долгой жизнью на острове (Wikivoyage, Rawai). Ни один из этих кадров не стоит больше нигде на хабе и на странице Банг Тао. Порядок 3:2, 4:5, 3:2 даёт в `placeCards` пару 7+5, а третью карточку справа.

Повтор на странице Банг Тао. `life.square` в блоке «Жизнь в Банг Тао» тоже `villa` (1:1, «Пример формата: вилла с бассейном»), так что кадр виллы встречается на странице дважды. Других кадров 1:1 из Банг Тао нет (1:1 есть только у `kata`, `naiharn`, `villa`). Варианты для разработчика: скрыть `life.square` на странице района, пока стоят форматы, или оставить повтор. Ставить в «Жизнь в Банг Тао» кадр Каты или Най Харна нельзя: подпись соврёт о месте.

Право собственности совпадает с блоком «Право собственности» и картой возражений В1. Формулировки сверяет юрист (список для клиента, п. 12).
