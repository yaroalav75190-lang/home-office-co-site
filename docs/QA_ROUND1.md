## Визуальные и смысловые правки
2. **Заглушки слишком громкие и их слишком много.** «[заглушка: вердикт брокера]», «[заглушка]» в каждом районе, «+7 [заглушка: номер для сайта]» набрано D2 антиквой. Политика: видимая заглушка остаётся только для данных клиента, которые нельзя знать (телефон, почта, юрлицо, часы, имена и фото команды, отзывы, год открытия, названия проектов). Её вид — тихий: Small, `ink-muted`, без квадратных скобок в крупном кегле. Общие сведения о районах (география, инфраструктура, тип застройки, сезонность) — это не факты о клиенте: их пишем по открытым источникам, осторожно, без оценок от имени брокера.
