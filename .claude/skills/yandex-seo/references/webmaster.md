# Яндекс.Вебмастер — техническая справка для SEO (сверено 2026-06)

> Справка переехала на `https://yandex.ru/support/webmaster/ru/<раздел>/<страница>`. Старые `.html` часто 404. Квоты инструментов обнуляются в 00:00 МСК.

## 1. Подтверждение прав на сайт
`www` и без `www`, http и https, поддомены — **разные сайты**, права подтверждаются отдельно.

| Способ | Формат |
|---|---|
| Meta-тег | `<meta name="yandex-verification" content="XXXX" />` в `<head>` **главной** страницы |
| HTML-файл | `yandex_XXXX.html` в корне |
| DNS TXT | TXT-запись с уникальным значением |
| Менеджер тегов | через Яндекс Метрику (YTM) или Google Tag Manager |
| Через регистратора (β) | если регистратор поддерживает |

Устарело: email/WHOIS-подтверждения в актуальной справке нет.

## 2. Индексирование («Страницы в поиске»)
Разделы: **Индексирование → Страницы в поиске** (вкладка «Исключённые»), «Структура сайта», «Проверить статус URL».

**Статусы исключённых (точные формулировки):**
- **«Страница признана малоценной или маловостребованной»** (с 03.2021). *Малоценная* — нет видимого контента / условный дубль. *Маловостребованная* — контент есть, но нет запросов под неё. **На ранжирование негативно НЕ влияет** — это не штраф, а сигнал о тонком/невостребованном контенте.
- «Страница дублирует содержание другой страницы» (Дубль).
- «Страница не является канонической» (`rel=canonical` указывает на другой URL).
- «Ошибка при загрузке или обработке роботом» — ответы **3xx/4xx/5xx**.
- «Индексирование запрещено в robots.txt / метатегом noindex».
- «Адрес признан неглавным» (зеркало). «Обнаружены нарушения».

Для индексации нужен ответ **200**. «Недостаточно качественная» — из старого классификатора; текущий аналог — «малоценная или маловостребованная».

**Переобход страниц** (Индексирование → Переобход страниц): приоритетный обход, индексация обычно **3–7 дней**. Лимит **динамический индивидуальный** (по качеству/размеру сайта, пересчёт ежедневно в 00:00 МСК). Старое фиксированное «20 URL/сутки» — устарело. Для объёмов — «Обход по счётчикам Метрики» или IndexNow.

## 3. robots.txt
Источники: `controlling-robot/robots-txt`, `robot-workings/clean-param`.

**Поддерживаются Яндексом:** `User-agent`, `Disallow`, `Allow`, `Sitemap`, `Clean-param`.

**Clean-param** — убирает дубли по незначащим GET-параметрам (сессии, сортировки, метки). Синтаксис:
```
Clean-param: p0[&p1&p2&...&pn] [path]
```
Параметры через `&`, опциональный префикс пути, регистрозависима, **макс. 500 символов** на правило.
Пример: `Clean-param: sid&sort /forum/*.php`

**ОТМЕНЕНО / НЕ УЧИТЫВАЕТСЯ:**
- **`Host` — отменена 20.03.2018.** Замена: постраничный 301 + инструмент «Переезд сайта». Строку можно удалить.
- **`Crawl-delay` — не учитывается с 22.02.2018.** Замена: настройка **«Скорость обхода»** в Вебмастере (по умолчанию «Доверять Яндексу»).

**Роботы:** общий идентификатор — `User-agent: Yandex` (всё семейство). Основной индексирующий — **YandexBot**. Прочие: YandexImages, YandexVideo, YandexMedia, YandexDirect (РСЯ), YandexMarket, YandexMetrika, YandexMobileBot, YandexFavicons, YandexNews, MirrorDetector. Проверка подлинности бота — обратный + прямой DNS на `yandex.ru/.net/.com`.

Дополнительно: инструмент Вебмастера **«Настройка GET-параметров»** (с 12.2025) — управление дублями/обходом без robots.txt.

## 4. Sitemap
- Формат **XML**, кодировка **UTF-8**, обязателен `<loc>`, ответ 200, URL ≤ 2048 символов.
- **Лимит одного файла: 50 000 URL и 50 МБ** (несжатый; у Яндекса 50 МБ, не 10).
- При превышении — **индексный файл (sitemapindex)** со ссылками на вложенные карты (каждая обрабатывается отдельно).
- Поддержка gzip (`.xml.gz`); 50 МБ считается до сжатия.
- Добавление: **Индексирование → Файлы Sitemap** → URL → «Добавить». Обработка до 2 недель.

## 5. IndexNow
`indexing-options/index-now`. Яндекс **официально поддерживает**. Ключ верификации — файлом в корне (для каждого поддомена свой ключ), передаётся в каждом запросе. Эндпоинты: `GET https://yandex.com/indexnow` (1 URL), `POST https://yandex.com/indexnow` (JSON, пакет). Отправлять только новые/изменённые/удалённые URL. Не гарантирует индексацию; работает параллельно с «Переобходом». Бонус — общий протокол с Bing.

## 6. Турбо-страницы — ⚠️ ЗАКРЫТЫ
Анонс **07.02.2025**, фактическое отключение ~апрель 2025. **Касается всех типов, включая интернет-магазины.** Раздел в Вебмастере отключён, турбо-метатеги/фиды неактуальны, старые Турбо-URL отдают 301 на оригиналы. Причина — рост скорости мобильного интернета и адаптивная вёрстка. **Опора 2025–2026 — собственная мобильная адаптивность + Core Web Vitals.** Не предлагать Турбо.

## 7. Региональность
Раздел **Представление в поиске → Региональность**. Источники региона:
1. **Вебмастер** — вручную (+ ссылка на страницу с контактами/адресом, модерация).
2. **Яндекс Бизнес / Справочник** — авто по карточке организации; **влияет на геозависимые запросы**; добавлять все филиалы.
3. **Яндекс Каталог — устарел** (обновления прекращены с 03.2018).

Геозависимые запросы («купить диван», «такси») учитывают регион; геонезависимые («как почистить ноутбук») — нет. Тест геозависимости: меняется ли топ при смене региона. Привязка к региону не исключает сайт из других регионов.

## 8. Зеркала и переезд сайта
**Директива `Host` устарела (2018).** Главное зеркало задаётся:
1. Постраничный **301-редирект** со всех неглавных зеркал на аналогичные страницы главного.
2. Инструмент **«Переезд сайта»** (указать новое главное зеркало).

Без 301 робот выбирает зеркало сам. **HTTPS / новый домен:** добавить новую версию в Вебмастер → убедиться, что не сгруппирована с чужими → настроить 301 → «Переезд сайта». Склейка — несколько дней.

## 9. Диагностика и фильтры/санкции
**«Диагностика» — категории по тяжести:** Фатальные (исключение из поиска) → Критичные (могут вести к исключению) → Возможные проблемы (качество/скорость индексации) → Рекомендации (советы, не ошибки). Уведомления по умолчанию — фатальные + критичные. Обновление раздела 11.2025 (ошибки/рекомендации + чек-лист).

**«Безопасность и нарушения»** (Оптимизация сайта → Безопасность и нарушения) — самый критичный тип. Перепроверка после «Нарушение исправлено → Отправить на проверку» — **до 30 дней**.

**ВАЖНО (2024+):** брендовые имена алгоритмов (АГС, Минусинск, Баден-Баден) **убраны из UI/справки**, сведены к единой странице нарушений. Актуальные формулировки: «Использование SEO-текстов», «Неожиданное перенаправление», «Мимикрия», «Клоакинг», «Нежелательное ПО» (вирусы/майнеры), «Социальная инженерия и обман пользователей», «Недобросовестные действия», **«Малополезный контент»**, **«Имитация действий пользователей»** (накрутка).

**Маппинг исторических санкций → причина → действие:**
| Историческое имя | Причина | Что делать |
|---|---|---|
| Баден-Баден (22.03.2017) | переоптимизированные SEO-тексты, переспам, «вода» | переписать тексты для людей, убрать переспам |
| Минусинск (15.05.2015) | покупные/искусственные SEO-ссылки | снять покупные ссылки, чистить профиль |
| Накрутка ПФ | имитация действий пользователей | полностью прекратить накрутку (иначе обнуление визитов продолжится) |
| АГС | некачественные сайты под продажу ссылок | поднять качество/полезность, убрать продажу ссылок |
| Аффилиаты | группа сайтов одного владельца для захвата позиций | развести/объединить площадки |

## 10. Инструменты Вебмастера
- **Проверка ответа сервера** — HTTP-код, SSL, блокировки robots.txt/noindex, выбор робота, `If-Modified-Since`.
- **Удаление страниц из поиска** — «По URL»/«По префиксу», **до 500 адресов/сутки**. Временная мера: нужен `noindex`/`404`/`410`/`Disallow`, иначе вернётся.
- **Переобход страниц** — лимит динамический (см. п.2).
- **Валидатор микроразметки** — Schema.org, микроформаты, микроданные, RDFa, Open Graph + типы Яндекса.
- **Мониторинг важных страниц** — до 100 адресов, история 100 изменений/URL.
- **Проверка мобильных страниц** — адаптивность + рекомендации.
- Плюс: XML-валидатор, проверка IP, проверка сертификата.
- Переименования: «Проверка robots.txt» → **«Анализ robots.txt»**; «Проверка карты сайта» → **«Анализ файлов Sitemap»**.

## 11. Микроразметка, понимаемая Яндексом
Источники: `schema-org/intro-schema-org`, `json-ld/about`.

**Синтаксисы:** Микроданные (`itemscope/itemprop`) — основной; **JSON-LD обязателен** для `BreadcrumbList` и `QAPage`; RDFa; Open Graph; микроформаты — только **hCard** и **hRecipe**. **YML** — товарный фид (раздел «Товары и цены»), не разметка страницы.

| Спецблок | Тип Schema.org | Синтаксис |
|---|---|---|
| Товары | `Product` + `offers` (price, priceCurrency ISO 4217) | Микроданные / YML |
| Каталоги | `OfferCatalog` + `Offer` | Микроданные |
| Организации | `Organization`/`LocalBusiness`, `PostalAddress`, `GeoCoordinates` | Микроданные + hCard |
| Рецепты | `Recipe` (время ISO 8601) | Микроданные + hRecipe |
| Вопрос-ответ | `QAPage`→`Question`→`Answer` (мобильная выдача) | **JSON-LD** |
| Хлебные крошки | `BreadcrumbList` (до 3) | **JSON-LD** |
| Видео / События | `VideoObject` / `Event` | Микроданные |

**Отзывы/рейтинги** как отдельный спецблок Яндекс **не описывает** (в отличие от Google) — звёзды в сниппете не гарантируются. Микроформаты урезаны до hCard/hRecipe; всё остальное — на Schema.org.

## 12. Метатеги и спецэлементы выдачи
- **`<meta name="robots">`** (для всех) / **`<meta name="yandex">`** (только Яндекс): `noindex`, `nofollow`, `noarchive`, `none` (=noindex,nofollow), `all`. При конфликте робот выбирает разрешающее. Если URL закрыт в robots.txt — метатег не сработает (робот его не увидит). HTTP-аналог: `X-Robots-Tag`.
- **Тег `<noindex>` Яндекса** (нестандартный, запрет части текста): валидно `<!--noindex-->…<!--/noindex-->`. Запрещает только текст; ссылки внутри обходятся.
- **Быстрые ссылки (sitelinks):** формируются автоматически; в Вебмастере можно включать/отключать и менять названия из предложенных (до 2 недель).
- **Фавикон:** SVG (рекоменд.), ICO/PNG/GIF/JPEG/BMP; размеры 120×120 / 32×32 / 16×16; без анимации; `<link rel="icon">` в `<head>` главной; появление ~2 недели.
- **Турбо-метатеги — отменены** (см. п.6).

## 13. Запросы и внешние ссылки
**Поисковые запросы:** метрики **Показы, Клики, Позиция, CTR**. Популярные — за 3 месяца (первые ~3000), ежедневное обновление.

**Аналитика/история запросов:** Показы, Клики, CTR, **Средняя позиция показа** и **Средняя позиция клика** (две РАЗНЫЕ метрики), доля кликов; разрезы «Динамика запросов» / «Анализ страниц». «Расширенная аналитика поисковых запросов по URL» (с 10.2025): динамика до ~1,5 лет, разрезы по регионам.
**Группы:** «Все запросы» (ТОП-50), «Избранные» (до 1000), свои группы (до 100 групп / 500 запросов). «Рекомендованные запросы» — подбор по тематике; удаляются, если не заходить >3 мес. β-инструмент «Подбор запросов и анализ рынка» (аналог Wordstat внутри Вебмастера).

**Ссылки** (раздел перезапущен 30.05.2024): URL источника и цель, **ИКС** ссылающегося (сортировка по умолчанию), HTTP-статус, анкор, дата; графики числа ссылок/доменов и битых ссылок; до 200 000 ссылок. Большое число ссылок само по себе не вредит без техник обмана.

## 14. ИКС (Индекс качества сайта)
`site-quality-index`. Запущен 31.08.2018 вместо тИЦ. «Показатель того, насколько сайт полезен и удобен пользователям». Официальные факторы: **размер аудитории, степень удовлетворённости (поведенческие), уровень доверия (пользователей и Яндекса)**. Формула закрытая, обновление ~раз в месяц.

**КЛЮЧЕВОЕ: «ИКС не влияет на ранжирование».** Это индикатор для самоконтроля и сравнения (Оптимизация сайта → Показатели качества; сравнение до 20 сайтов). 27.02.2026 — обновлён механизм расчёта (быстрее реагирует, сильнее затронул молодые сайты; старое и новое значения несравнимы; новых факторов нет; на ранжирование по-прежнему не влияет).

**Знаки качества:** «Выбор пользователей» / «Популярный сайт» **отключены 19.10.2022** (если встречаются в старых материалах — устарело). Действуют знаки официальности (госорганизация, финорганизация по данным ЦБ РФ) и знак магазина — выдаются автоматически.

## Сводка «что устарело» (критично)
1. Директива `Host` (отм. 2018) → 301 + «Переезд сайта».
2. Директива `Crawl-delay` (не учитывается с 2018) → «Скорость обхода».
3. Турбо-страницы + турбо-метатеги (закрыты 02–04.2025), включая для магазинов.
4. Знаки «Популярный сайт» / «Выбор пользователей» (отключены 19.10.2022).
5. Брендовые санкции (АГС/Минусинск/Баден-Баден) убраны из UI → обобщённые нарушения.
6. Яндекс Каталог как источник региона (с 03.2018).
7. тИЦ → ИКС (2018); ИКС обновлён 02.2026, по-прежнему не влияет на ранжирование.
8. Лимит переобхода — динамический, не «20/сутки».
