# Чек-листы Yandex SEO (рабочие, под РФ-поиск)

Отмечай выполненное `[x]`. Приоритет под Яндекс: **ПФ → коммерческие факторы → контент/семантика → техника → ссылки → региональность → GEO**.

## 1. Технический чек-лист (индексация)
- [ ] Права на сайт подтверждены в Вебмастере (для всех нужных хостов: с/без www, https).
- [ ] Метрика установлена в `<head>`, точный показатель отказов включён, `<noscript>`-пиксель на месте.
- [ ] Вебмастер ↔ Метрика связаны; «Обход по счётчикам» включён.
- [ ] robots.txt: нет `Host` (удалить), нет `Crawl-delay` (использовать «Скорость обхода»); `Clean-param` закрывает дубли по GET-параметрам.
- [ ] Sitemap.xml валиден (UTF-8, ≤50 000 URL и ≤50 МБ на файл), добавлен в Вебмастер; при объёме — sitemapindex.
- [ ] IndexNow внедрён (ключ-файл в корне, пинг на новые/изменённые/удалённые URL).
- [ ] Канонизация: `rel=canonical`, «Настройка GET-параметров»; нет дублей-каннибалов.
- [ ] Главное зеркало склеено постраничным 301 + «Переезд сайта»; весь сайт на HTTPS.
- [ ] Нет Турбо-зависимостей (технология мертва); сайт сам адаптивен; Core Web Vitals в норме.
- [ ] «Страницы в поиске → Исключённые» проверены; «малоценные/маловостребованные» — это сигнал тонкого контента, разобраться (не штраф, но повод усилить страницы).
- [ ] Ответы сервера 200 на нужных URL; 404/410 на удалённых; нет цепочек редиректов.
- [ ] Диагностика Вебмастера: нет фатальных/критичных проблем.

## 2. Коммерческий чек-лист (для коммерческих запросов — закрывать ЦЕЛИКОМ)
- [ ] Ассортимент полный, категории и фильтры проработаны (ассортимент — мультипликатор).
- [ ] Цены актуальны, у каждого товара явно указано наличие.
- [ ] Доставка и оплата расписаны детально, **с разбивкой по регионам**.
- [ ] Контакты: телефон, адрес, реквизиты, режим работы, мессенджеры, форма/онлайн-консультант.
- [ ] Отзывы: текст + фото + видео, на сайте И на сторонних площадках (Карты, маркетплейсы, отзовики).
- [ ] Гарантии, возврат, сертификаты, доверие (о компании, кейсы, лицензии).
- [ ] Корзина и формы удобны, минимум шагов до заказа.
- [ ] Микроразметка `Product`+`offers` (price, priceCurrency=RUB), `Organization`/`LocalBusiness`.
- [ ] Карточки товара уникальны и информативны (характеристики, фото, описание — не дубль производителя).

## 3. Контентный / текстовый чек-лист
- [ ] Семантика собрана и кластеризована по интенту; гео-зависимые отделены от гео-независимых (источник: `_seo/semantics.md` если есть).
- [ ] Тексты для людей: тема раскрыта семантически, без переспама и «воды» (риск понижения за SEO-тексты).
- [ ] Нет автогенерата без ценности (апдейт качества контента 03.2024).
- [ ] Title/Description под интент, без переспама ключей; H1 один, логичная иерархия H2/H3.
- [ ] Под нейропоиск/Алису: прямой ответ в первых 2–3 предложениях раздела; схема «определение → детали/цифры → вывод»; короткие предложения, таблицы, списки, FAQ.
- [ ] E-E-A-T-аналог (Proxima): авторство, экспертность, цифры/кейсы, достоверность, особенно в YMYL.
- [ ] Перелинковка усиливает посадочные и снижает pogo-sticking.
- [ ] Уникальность и свежесть контента; устаревшие страницы обновлены.

## 4. Поведенческий чек-лист (легально)
- [ ] Релевантность посадочной интенту запроса (первый экран отвечает на запрос).
- [ ] Скорость загрузки и мобильная адаптивность (Core Web Vitals).
- [ ] Понятная навигация, перелинковка, ответы на смежные вопросы → глубина/время.
- [ ] Страница закрывает запрос лучше топ-конкурентов → меньше возвратов в выдачу.
- [ ] Меряем прокси в Метрике: отказы (точный показатель!), время, глубина, карты скроллинга/кликов, Вебвизор.
- [ ] ❌ Никакой накрутки ПФ (хостовая санкция / молчаливое незасчитывание визитов).

## 5. Локальный / региональный чек-лист
- [ ] Регион(ы) заданы в Вебмастере (Региональность, с подтверждающим URL).
- [ ] Яндекс Бизнес: карточка заполнена (NAP, график, услуги с ценами, фото/видео); все филиалы добавлены.
- [ ] Отзывы на Картах собираются, на каждый есть ответ (сигнал и для локального ранга, и для нейроответов).
- [ ] Контент под локальные запросы (город в Title/H1/тексте там, где уместно и естественно).
- [ ] NAP консистентен на сайте и во всех внешних карточках/каталогах.

## 6. GEO под «Алису AI» (видимость в ИИ-ответах)
- [ ] Контент структурирован фрагментами (алгоритм берёт фрагменты, не страницы).
- [ ] Прямой ответ на вопрос в первых 2–3 предложениях раздела.
- [ ] H2 как вопросы/темы; схема «определение → детали/цифры → вывод».
- [ ] Таблицы, нумерованные списки, FAQ-блоки (`QAPage` JSON-LD для мобайла).
- [ ] Факты, цифры, даты, источники → выше шанс цитирования.
- [ ] E-E-A-T: авторство, экспертиза, актуальность.
- [ ] Мониторинг KPI «Видимость сайта в Алисе AI» (Вебмастер → Эффективность), динамика Share of Voice, конкуренты-источники.
- [ ] Переориентация части стратегии на запросы с переходами (где ИИ-ответ не закрывает задачу полностью — транзакционные/коммерческие).

## 7. Диагностика падения трафика (дерево решений)
1. **Резкое падение + уведомление в Вебмастере** → фильтр. Открыть «Безопасность и нарушения», идентифицировать формулировку, см. маппинг в `webmaster.md` §9 → устранить причину → отправить на проверку (до 30 дней).
2. **Резкое падение без уведомления** → проверить технику: robots.txt/noindex/canonical, ответы сервера, «Страницы в поиске → Исключённые», случайный `Disallow`/деплой.
3. **Плавное падение по информационным запросам** → влияние нейроответов Алисы (zero-click). Проверить «Видимость в Алисе AI», переориентировать на запросы с переходами + GEO.
4. **Потеря позиций без фильтра** → ПФ (выросли отказы? сегмент по Яндексу в Метрике), коммерческие факторы у конкурентов, свежесть/полнота контента, региональная привязка.
5. **Падение только в Яндексе (Google стабилен)** → почти всегда ПФ / коммерческие факторы / региональность / фильтр Яндекса, не общая техника.
6. Не списывать на «апдейт» до исключения техники, фильтров и ПФ.

## 8. Снятие фильтра (порядок)
1. Идентифицировать нарушение точно (Вебмастер → Безопасность и нарушения; бренды убраны, формулировки обобщены).
2. Устранить **причину**, а не симптом:
   - SEO-тексты/переоптимизация → переписать для людей, убрать переспам/воду.
   - SEO-ссылки → снять покупные, чистить профиль.
   - Накрутка ПФ → полностью прекратить (иначе незасчитывание визитов продолжится).
   - Малополезный контент → усилить ценность/уникальность или удалить тонкие страницы.
3. «Нарушение исправлено» → «Отправить на проверку». Ждать до 30 дней. Не маскировать, не торопить.

## Красные флаги (никогда не предлагать)
Накрутка ПФ · покупка SEO-ссылок пачками · клоакинг · дорвеи · автогенерат ради объёма · переспам · аффилиат-сетки для захвата выдачи · маскировка вместо устранения причины фильтра · Турбо-страницы (мертвы) · директивы `Host`/`Crawl-delay` (не работают).
