# Яндекс.Метрика для SEO (сверено 2026-06)

> Справка: `yandex.ru/support/metrica/ru/<раздел>`. Старые `.html` частично 404.
> **Что Метрика для SEO НЕ заменяет:** запросы/позиции из выдачи — только Вебмастер. Метрика обезличивает поисковые фразы и не видит запросы, которые Google не передаёт в реферере.

## 1. Установка счётчика
Асинхронный `tag.js` с `https://mc.yandex.ru/metrika/tag.js` (устарел `watch.js`); инициализация `ym(НОМЕР, "init", {...})`. Альт-домен при блокировке — `mc.yandex.com`.

```html
<script type="text/javascript">
   (function(m,e,t,r,i,k,a){/*...loader...*/})(window, document, "script",
   "https://mc.yandex.ru/metrika/tag.js", "ym");
   ym(XXXXXXXX, "init", {clickmap:true, trackLinks:true,
      accurateTrackBounce:true, webvisor:true});
</script>
<noscript><div><img src="https://mc.yandex.ru/watch/XXXXXXXX"
   style="position:absolute; left:-9999px;" alt="" /></div></noscript>
```
`<noscript>`-пиксель обязателен. Код: **Настройка → вкладка «Счётчик» → «Скопировать код»**, ставить в `<head>`.

**Параметры init** (умолчания): `accurateTrackBounce`(true), `clickmap`(true), `trackLinks`(true), `webvisor`(false), `trackHash`(false — SPA/якоря), `ecommerce`(false), `defer`(false — SPA), `sendTitle`(true), `params`/`userParams`, `trustedDomains`, `triggerEvent`.

**Яндекс Тег Менеджер (ЯТМ):** бесплатный GTM-аналог. Активация (владелец счётчика): Настройка → Счётчик → блок «Тег менеджер» → Вкл. + «Пользовательский HTML». Тег в ЯТМ: «Теги» → «Добавить тег» → шаблон «Яндекс Метрика» → номер → **«Опубликовать»** (без публикации не применяется).

## 2. Связка с Вебмастером (важно для SEO)
1. Метрика: **Настройка → Счётчик → «Привязать к Вебмастеру»**.
2. Вебмастер: **Настройки → «Привязка к Яндекс Метрике» → «Подтвердить»** (если вы владелец и сайта, и счётчика — авто).
3. Вебмастер: **Индексирование → «Обход по счётчикам»** → включить (робот обходит страницы со счётчиком → ускоряет индексацию).

Даёт: ускорение индексации + отчёт «Запросы» из Вебмастера внутри Метрики (Показы, Клики, CTR, Позиция — среднесуточная).

## 3. Настройки, важные для SEO
- **Вебвизор / карта скроллинга / аналитика форм / карта кликов** — одна опция включает всё; в коде `webvisor:true`. Запись сессий ~15 дней; нужна кодировка UTF-8.
- **Точный показатель отказов (`accurateTrackBounce`):** **отказ = 1 просмотренная страница И визит < 15 сек И нет «неотказного» события (цели)**. Тайм-аут настраивается в мс: `accurateTrackBounce: 20000`. При `false` отказом считается ЛЮБОЙ одностраничный визит независимо от времени → завышает отказы. **Всегда включай точный показатель** — иначе SEO-выводы по отказам неверны.
- **Тайм-аут визита:** 30–360 мин (умолч. 30) — НЕ путать с 15-сек тайм-аутом отказа.
- **Electronic commerce:** опция + `ecommerce:"dataLayer"`; совместимо с GA4 / Enhanced Ecommerce.
- **Межсайтовая аналитика:** «Дополнительные адреса сайтов» + опция «Включая поддомены»; `trustedDomains` в коде.

## 4. Цели и ретаргетинг
**Типы целей:** JavaScript-событие; Количество просмотров (= «глубина» как цель); Посещение страниц (URL); Клик на email (`mailto:`); Клик по телефону (`tel:`); Клик по кнопке; Отправка формы; Переход в мессенджер; Переход в соцсети; Скачивание файла; Поиск по сайту; Возврат из платёжной системы; Звонки; Чаты; **Мультицель** (ИЛИ); **Составная цель** (многошаговая).

Уточнения: **«Время на сайте» — НЕ тип цели** (это метрика). До 10 условий на цель (по ИЛИ). URL-условия: совпадает / содержит / начинается с / регулярка (**RE2**). JS-цель: строковый ID → `ym(XXXX,'reachGoal','ID')`.

**Ретаргетинг:** любая цель/сегмент доступны в Яндекс Директе и Аудиториях. Данные в сегмент — в течение 180 мин, пересчёт ежедневно.

## 5. Отчёты, критичные для SEO
- **Источники → Поисковые системы** — по каждому поисковику отказы/глубина/время/конверсии. Сегментируй Яндекс vs Google.
- **Источники → Поисковые запросы** — фразы из реферера. **Скрываются («недостаточно данных»/обезличены), когда:** (1) посещаемость по строке < 10; (2) применён деанонимизирующий срез (Страница входа, Возраст и т.п.); (3) источник не передаёт запрос (аналог «not provided», особенно Google).
- **Содержание → Страницы входа** / **Содержание → Популярное** — посадочные страницы.
- **Источники, сводка** — все каналы: визиты, % отказов, глубина, время, конверсия, доход.
- ⚠️ **Отчёта «Долгие клики» / «Качество поиска» и метрики pogo-sticking в Метрике НЕТ** — это термины практики, не интерфейс. Качество поискового трафика оценивай штатными метриками (отказы/глубина/время/конверсия) в отчётах по поисковикам.

**Метрика vs Вебмастер по запросам:** Метрика = только переданные в реферере фразы, по визитам, с поведением/конверсией, но с сильным обезличиванием. Вебмастер = запросы из самой выдачи Яндекса (показы, клики, CTR, средняя позиция, в т.ч. без кликов). Для полной картины — оба.

## 6. Сегментация
Конструктор над любым отчётом или Анализ данных → Сегментация. Типы условий: **«Визиты, в которых»** (по визиту), **«Для людей, у которых»** (по всем визитам пользователя), **«За время»**. Готовые срезы: по поисковику (`Источники → Последний источник → Поисковая система`), по устройству (`Технологии → Устройства`), по региону (`География`).

## 7. Поведенческие факторы — прокси и пределы
**Измеримо:** отказы, время, глубина, карта скроллинга (доскроллы), карты кликов/ссылок, аналитика форм, Вебвизор.
**НЕ показывает напрямую:**
- **Pogo-sticking / возврат в выдачу** — именованной метрики нет; приближается косвенно (отказ + короткое время + сегмент по поисковому источнику).
- **ПФ как ранжирующий сигнал** — «серый ящик»: CTR в выдаче, возвраты, последний клик считаются на стороне ПОИСКА, не в Метрике. Метрика даёт прокси, не сам сигнал.

**Накрутка ПФ (официально):** раздел Вебмастера «Имитация действий пользователей» — поисковый спам, понижение на длительный срок. В 2024–2026 чаще — **молчаливое незасчитывание фродовых визитов**. Снятие: Безопасность и нарушения → «Нарушение исправлено» → «Отправить на проверку» (до 30 дней). **Не помогать с накруткой.**

## 8. Роботность / антифрод
По умолчанию данные показываются **«без роботов»**. Переключатель «Данные: с роботами» открывает долю роботного трафика и отчёт «Роботы». С 09.07.2025 в Logs API / Data Streaming есть признак **`isRobotPro`** (роботность по антифроду Директа + поведению, для Метрики Про).

## 9. API
OAuth-токен. Четыре API: **Management** (счётчики/цели/доступы), **Reporting** (выгрузка отчётов), **Data Import** (расходы/CRM/звонки/офлайн-конверсии), **Logs API** (raw-данные).
**Logs API:** типы `visits` (`ym:s:*`: visitID, pageViews, visitDuration, bounce, startURL/endURL, regionCity, deviceCategory, clientID) и `hits` (`ym:pv:*`: URL, referer, UTM, lastSearchEngine). Период ≤ 1 год; `fields` ≤ 3000 символов; данные текущего дня недоступны.

## 10. Ecommerce dataLayer
Контейнер `dataLayer`, `window.dataLayer.push()`, совместимость с GA4. События: impressions, click, detail, add, remove, purchase, promoView, promoClick. Поля: `currencyCode` (ISO 4217, напр. RUB); `products[]` — `id`/`name` (минимум), `price`, `brand`, `category` (до 5 уровней через `/`), `quantity`, `variant`, `position`, `list`; для purchase — `actionField.id` (обязателен), `revenue`.

## 11. Конфиденциальность (152-ФЗ) — для РФ-сайтов
Метрика собирает ПДн (IP, cookie-ID, устройство, поведение). **Локализация:** хранение ПДн граждан РФ в базах на территории РФ (ст. 18 152-ФЗ). Контактные данные передаются хешированными; есть маскировка IP. Отключение сбора: `window['disableYaCounterXXXXXXXX'] = true`. «Ограниченный режим» — меньше данных, только first-party cookie (работает в Safari/Firefox с блокировкой third-party).
**На практике для РФ-сайта нужно:** политика конфиденциальности, cookie-баннер/согласие, отказ от лишнего сбора, корректные правовые отношения с Яндексом.

## Главные предостережения
1. №1 ограничение для SEO — **обезличивание поисковых фраз** (< 10 визитов / деанон-срезы) и непередача запросов Google → запросы/позиции бери в **Вебмастере**.
2. «Время на сайте» — не цель; «глубина» как цель = тип «Количество просмотров».
3. Отчётов «Долгие клики»/«Качество поиска» и метрики pogo-sticking в Метрике нет.
4. ПФ как фактор ранжирования — серый ящик: Метрика = прокси, не сигнал поиска.
5. Всегда включай «точный показатель отказов», иначе отказы завышены и выводы ложны.
