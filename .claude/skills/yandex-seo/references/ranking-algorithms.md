# Алгоритмы и факторы ранжирования Яндекса (сверено 2026-06)

Легенда: 🟢 официально подтверждено Яндексом · 🟡 отраслевые наблюдения/реконструкции (подавать как гипотезу, НЕ как факт Яндекса).

Сквозной тренд 2024–2026: центр тяжести сместился к **генеративному поиску (Нейро → «Поиск с Алисой» → «Алиса AI»)**. Новый KPI вебмастера — видимость в ИИ-ответах (GEO).

## 1. Хронология алгоритмов
| Алгоритм | Дата | Суть | Дост. |
|---|---|---|---|
| **MatrixNet** | 2009 | ML в формуле ранжирования (бустинг над деревьями); тысячи факторов, нелинейность. Базис стека. | 🟢 |
| **Палех** | 02.11.2016 | Первая нейросеть (DSSM): смысл запроса ↔ **Title**. Длинный хвост, редкие НЧ. | 🟢 |
| **Королёв** | 22.08.2017 | Смысл запроса ↔ **текст всей страницы**. Нейрооценка ~200 000 страниц/запрос. | 🟢 |
| **Вега** | конец 2019 | Удвоение базы, семантические кластеры, гиперлокальность, эксперты/Толока. (Не 2020!) | 🟡 |
| **YATI** | 11.2020 | Переход на **трансформеры** (аналог BERT). Смысл важнее точных вхождений; обучен на оценках асессоров + клики. «Крупнейшее улучшение за 10 лет». | 🟢 |
| **Y1** | 10.06.2021 | ~2000 улучшений на YATI + YaLM; экономия времени пользователя. | 🟢 |
| **Y2** | 28.11.2022 | Многоэтапные задачи; метрики **Проксима** и **Профицит**. | 🟢 |
| **Proxima** | 2021–2022 | Не алгоритм, а **интегральная метрика качества** (коммерческие + конверсионные + лояльностные + экспертные + доверие). Рядом — «Антикачество» (штраф за спам), «Профицит». | 🟡 (концепт 🟢) |

**Сейчас:** ядро — трансформеры (наследие YATI) поверх MatrixNet и индекса; сверху генеративный слой YandexGPT 3→5 → «Алиса AI». Тренд: рост веса поведения и качества, снижение веса покупных ссылок. 🟡

> ⚠️ «Оригами/Тайфун» как актуальные алгоритмы 2025, расшифровка «ЭПОС», «обновления YATI 2025» — официально НЕ анонсированы. Не ссылаться как на реальные.

## 2. Поведенческие факторы (ПФ)
- Один из **важнейших** факторов Яндекса, вес выше, чем у Google. Сигналы: CTR в выдаче, время, отказы, глубина, **возвраты в выдачу (pogo-sticking)**, целевые действия. 🟡 (Google прямым фактором ПФ не называет.)
- **«Многорукий бандит»** (2015): рандомизация выдачи — временно поднимает кандидатов выше топа, чтобы собрать по ним ПФ; убирает «закостенелость» топ-10. 🟢
- **Антинакрутка (офиц.):** имитация действий = поисковый спам; ограничения на уровне **хоста**, исторически 8–12 мес., падение на 20–30+ позиций. 🟢
- **Ключевой сдвиг 2024–2026:** вместо явных банов система всё чаще **просто не засчитывает подозрительные визиты** (бюджет горит, позиции стоят). Курс: «не учитывать фродовые сигналы, чтобы накрутка не работала по умолчанию». 🟢 (заявления) / 🟡 (механика).
- **Вывод для практики:** растить ПФ только реальным улучшением UX/контента/скорости/релевантности. Накрутка — деньги на ветер + риск хоста.

## 3. Коммерческие факторы (коммерческие запросы)
- Происхождение: 11.2011, работа «Ranking Factors for E-Commerce Web Search». Четыре офиц. группы: **доверие к компании, дизайн/удобство, качество товара/услуги, объективность цен**. 🟢
- **Отдельная группа, влияет ТОЛЬКО по коммерческим запросам. У Google аналога-группы нет.** 🟢 (концепт)
- Учитывается (🟡 детализация): ассортимент (мультипликатор), актуальные цены и явное наличие, доставка/оплата с детализацией по регионам, контакты/реквизиты/мессенджеры, конверсионные элементы (корзина/формы), гарантии/возврат, онлайн-консультант, отзывы (текст/фото/видео, на сайте и на сторонних площадках), траст.
- Формула `R = V×(2T+U+D+2S)` и веса «60–70%» — **отраслевая реконструкция, Яндекс не публиковал.** 🟡

## 4. Текстовые факторы и переоптимизация
- **Баден-Баден** (22–23.03.2017): **не отдельный фильтр, а часть алгоритма** для определения переоптимизированных текстов. Две формы: запросозависимое понижение страниц (6–30 позиций) и хостовый постфильтр «Переоптимизация». Ловит переспам ключей, «воду», автогенерацию. Рекомендация Яндекса — «писать полезные тексты для людей». 🟢
- Эволюция оценки текста: плотность ключей / BM25 → нейросети (Палех/Королёв) → **YATI** (смысл важнее точных вхождений). BM25-сигналы остаются как один из факторов, решают нейромодели. 🟢
- «LSI» — отраслевой термин, Яндекс не использует; важна тематическая полнота, а не плотность. 🟡
- **Практика:** раскрывать тему семантически, не переспамить, не лить воду ради объёма, не публиковать автогенерат без ценности (апдейт качества контента 22.03.2024 усилил борьбу с бесполезными ИИ-текстами 🟢).

## 5. Ссылочные факторы
- **12.03.2014:** Яндекс перестал учитывать ссылки по части коммерческих запросов (Москва + ряд тематик) — эксперимент, позже ссылочное вернули. «Полная отмена» — миф. 🟢/🟡
- **Минусинск** (анонс 15.04.2015, запуск 15.05.2015): пессимизация за покупные SEO-ссылки; понижение на 10–20+ позиций на все площадки владельца, с предупреждением в Вебмастере. За год: ограничено 7103 сайта, 5705 исправились. 🟢
- **Сейчас:** офиц. позиция (2018) — «вес SEO-ссылок значительно ослаб». Работают качественные ссылки с авторитетных тематических площадок; сомнительные — вредят. Хостовые метрики > постраничных. «−30% веса в 2024» — оценка сообщества. 🟡
- **Практика:** не закупать пачками с бирж; наращивать естественные/тематические ссылки, упоминания бренда, PR.

## 6. E-E-A-T-аналог: Proxima и доверие
- **Proxima** (2020–2021, платформа «Андромеда»): интегральная **метрика качества**, объединяющая коммерческие, лояльностные, конверсионные, экспертные сигналы и доверие. 🟢
- Сигналы экспертности/доверия сначала — к **YMYL** (медицина/финансы/право), затем шире. Учитывается авторитетность автора и достоверность данных. 🟢
- Смежные метрики: **Профицит** (успешность решения задачи через сумму взаимодействий с выдачей), **Антикачество** (недобросовестные сайты по репутации/отзывам/инфофону). 🟢
- Отличие от Google: E-E-A-T у Google — рамка для асессоров без единой публичной метрики; у Яндекса Proxima — **именованная алгоритмическая метрика** в ранжировании. Аббревиатуру E-E-A-T Яндекс не использует. 🟢

## 7. Региональное ранжирование
- **Геозависимые** vs **геонезависимые** запросы (тест: меняется ли топ при смене региона). 🟡
- Привязка: Вебмастер → Региональность (с подтверждающим URL) + **Яндекс Бизнес** (карточка на Картах/в локальной выдаче). Локальные сигналы: полнота/актуальность NAP, график, **отзывы и ответы на них**, рейтинг, фото/видео, близость, известность бренда. Отзывы — основной источник и для локального ранга, и для нейроответов. 🟡
- У Google таргетинг только на уровне страны; точечной геопривязки к городу, как у Яндекса, нет. 🟢/🟡

## 8. Нейро / «Поиск с Алисой» / «Алиса AI» (генеративный слой)
- **Нейро — 16.04.2024:** Поиск + YandexGPT с подтверждением источниками. Механика: переформулировка → отбор **топ-документов** → генерация ответа. Октябрь 2024 — встроен в обычный Поиск. 🟢
- Эволюция: YandexGPT 5 (02.2025) → **«Поиск с Алисой»** заменил Нейро (22.05.2025, YandexGPT 5.1 Pro: мини-статьи, режим рассуждений, вкладки Товары/Квартиры/Финансы) → семейство **«Алиса AI»** (28.10.2025, отказ от бренда YandexGPT) → Алиса AI прямо из Поиска (12.2025) → усиленная Алиса AI + вертикаль «Услуги» (04.2026). 🟢
- **Влияние:** рост zero-click по информационным запросам (оценки сообщества — потери органики РФ 33–38% в 2025, инфо-сайты сильнее; ~60% сессий без перехода 🟡). Контрпозиция Яндекса: у ~60% топ-медиасайтов трафик вырос. 🟢
- **GEO-тактика (как попадать в ИИ-ответ):** алгоритм берёт **фрагменты, а не страницы** → прямой ответ в первых 2–3 предложениях раздела; схема H2 «определение → детали/цифры → вывод»; короткие предложения, таблицы, списки, FAQ; E-E-A-T (цифры/кейсы/авторство); Schema.org. 🟡
- **KPI:** «Видимость сайта в Алисе AI» (Вебмастер → Эффективность, с 07.04.2026) — доля запросов с упоминанием сайта в быстрых ответах, динамика **Share of Voice**, конкуренты-источники; обновление еженедельно; на ранжирование не влияет (аналитика). 🟢

## 9. ИКС (Индекс качества сайта)
22.08.2018 заменил тИЦ. Офиц. факторы: размер аудитории, удовлетворённость, доверие (+ др.); формула закрытая; обновление ~раз в месяц. **Прямого влияния на ранжирование Яндекс не декларирует** — индикатор качества, не ранжирующий фактор. Конкретика «время/глубина/отказы/CWV в ИКС» — отраслевая интерпретация 🟡. 27.02.2026 — обновлён расчёт (быстрее реагирует, сильнее затронул молодые сайты; на ранжирование по-прежнему не влияет 🟢).

## 10. Апдейты 2024–2026
- **22.03.2024:** обновление алгоритма качественного контента — борьба со спамом и бесполезными ИИ-текстами, рост веса экспертности/оригинальности/антикликбейта (часть Проксимы). 🟢
- **Турбо отключены** (07.02.2025 анонс, ~04.2025 факт) — замена 301 на оригиналы; на ранжирование не повлияло. 🟢
- **ИКС:** обновление расчёта 27.02.2026. 🟢
- Главное направление антиспама — **антинакрутка ПФ**; Минусинск действует, нового апдейта нет. 🟢/🟡
- Новые инструменты Вебмастера: «Видимость в Алисе AI» (04.2026), «Настройка GET-параметров» (12.2025), обновление «Диагностики» (11.2025), «Расширенная аналитика запросов по URL» (10.2025). 🟢

## 11. Яндекс vs Google — практические отличия
Контекст: доля Яндекса в РФ ~68% (2025), прогноз 71–73% (2026); Google ~24–25%. 🟡 Приоритет — Яндекс.
1. **ПФ:** Яндекс — самостоятельный объект оптимизации и борьбы (антинакрутка); Google — косвенно. Накрутку не использовать.
2. **Коммерческие факторы:** у Яндекса — отдельный обязательный чек-лист; у Google группы нет.
3. **Текст:** Яндекс — избегать переспама (Баден-Баден); Google — упор на экспертный авторский контент.
4. **Ссылки:** нужны обоим осторожно; в Яндексе сильнее влияют ближе к топ-3, хостовые > постраничных.
5. **Региональность:** Яндекс — обязательна (Вебмастер + Яндекс Бизнес, геопривязка к городу); Google — страна.
6. **Ускоренные страницы мертвы:** Турбо отключены (2025), AMP не нужен. Замена — адаптив + Core Web Vitals.
7. **Индексация:** внедрить **IndexNow** (Яндекс + Bing).
8. **2026:** отслеживать видимость в Алисе AI (Share of Voice), оптимизировать под фрагментарные ИИ-ответы.

- «Новые алгоритмы 2025» (Оригами/Тайфун) — не анонсированы официально.
- Вега — конец 2019.
- Перечень метрик внутри ИКС — интерпретация; официально только аудитория/удовлетворённость/доверие.
- «Молчаливое незасчитывание накрутки» — консенсус сообщества, подтверждаемый уведомлениями, без развёрнутой офиц. механики.
