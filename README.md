# Home Office & Co — сайт агентства недвижимости

Промо-версия сайта для показа клиенту. Next.js 16, GSAP и Lenis, арт-дирекция «Береговая линия».
Страницы: главная, Пхукет, Банг Тао, сопровождение сделки, квиз подбора, контакты, политика и согласие.

## Структура

| Папка | Что внутри |
| --- | --- |
| `site/` | Сайт (Next.js). Запускается отсюда |
| `docs/` | Бриф, план сборки, арт-дирекция, тексты, отчёты проверок (`docs/qa/`), решения для промо (`docs/DEMO_DECISIONS.md`) |
| `.claude/` | Команда агентов и навыки, которыми сайт собирался |
| `tools/` | Скрипты: декодирование анкеты, листы скриншотов |
| `home-office-co-prototype.html` + `img/` | Ранний кликабельный прототип |

## Запуск

Нужны Node.js 22+ и pnpm.

```bash
cd site
pnpm install
pnpm build
pnpm demo
```

`pnpm demo` поднимает собранный сайт на http://localhost:3100 в режиме показа: формы показывают
настоящие экраны «спасибо», а каждая заявка печатается в терминал. Этот режим только для
презентации, на публичном сайте его использовать нельзя: посетитель увидит «спасибо», а брокер
ничего не получит. Он отключается сам, как только задана хотя бы одна интеграция ниже.

Для разработки: `pnpm dev` (порт 3000). Обычный запуск без режима показа: `pnpm start`.

## Переменные окружения

Без них заявки на боевом сервере возвращают ошибку, а форма показывает телефон брокера.

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Заявки в Telegram брокеру |
| `AMOCRM_SUBDOMAIN`, `AMOCRM_ACCESS_TOKEN`, `AMOCRM_PIPELINE_ID` | Сделки в amoCRM |
| `AMOCRM_STATUS_ID`, `AMOCRM_RESPONSIBLE_USER_ID`, `AMOCRM_TRACKING_FIELDS` | Необязательно: этап, ответственный, поля для UTM |
| `NEXT_PUBLIC_YM_ID` | Счётчик Яндекс Метрики |
| `NEXT_PUBLIC_SITE_URL` | Домен для canonical и разметки, если не `https://homeofficeco.com` |
| `LEAD_RATE_LIMIT` | Необязательно: лимит заявок с одного адреса |
| `LEAD_DEMO_NO_DELIVERY=1` | Режим показа, см. выше. На боевом сервере не задавать |

Хостинг с Node.js (Vercel, VPS): корневая папка проекта — `site`, команда сборки `pnpm build`.
